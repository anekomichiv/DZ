| Этап SDLC (Agile)           | Деятельность команды разработки                   | Роль QA                                                |
|-----------------------------|---------------------------------------------------|--------------------------------------------------------|
| **Планирование**            | Определение задач спринта, декомпозиция user story| Уточнение требований, участие в планировании тестирования |
| **Анализ требований**       | Анализ бизнес-требований                          | Создание acceptance criteria, уточнение критериев готовности (DoD) |
| **Проектирование (Design)** | Проектирование архитектуры и UI                   | Подготовка тест-кейсов, тестовой стратегии, тестовых данных |
| **Разработка (Implementation)** | Написание кода и unit-тестов                    | Разработка автоматизированных тестов, участие в code review |
| **Тестирование (Testing)**  | Интеграция и сборка                               | Выполнение ручного и автоматизированного тестирования, отчёт о дефектах |
| **Внедрение и сопровождение** | Деплой на продакшн, поддержка                    | Финальное регрессионное тестирование, тестирование hotfix, ретроспектива по качеству |
